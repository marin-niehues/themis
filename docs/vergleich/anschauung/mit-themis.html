themis
Regeln Verteilung GitHub

themis gibt jeder Claude-Code-Session eures Teams dieselben Schreibregeln.

Das Plugin lädt beim Start einer Session eine gemeinsame Regeldatei aus einem GitHub-Repository und gibt sie Claude als Kontext. Nach diesen Regeln schreibt Claude Texte, Code und Oberflächen ohne die Muster, an denen man Ausgaben von Sprachmodellen erkennt.

Installation im Terminal 
$gh repo clone marin-niehues/themis ~/themis$~/themis/install.sh

Der erste Befehl braucht die GitHub CLI mit Zugriff auf das Repository. Den Quelltext findet ihr im Repository auf GitHub.

Was Claude nach den Regeln anders schreibt

Die Regeldatei listet Muster auf, die in Texten von Sprachmodellen häufiger vorkommen als in Texten von Menschen. Sie nennt zu jedem Muster einen Ersatz und gilt für Antworten im Chat, Dokumente, Code, Commit-Nachrichten und Oberflächen.

Auszug aus RULES.md, gekürzt
BereichMusterErsatz
TextGedankenstrich als SatzzeichenKomma, Punkt, Doppelpunkt oder Klammer
Ankündigungen wie „Seien wir ehrlich“die Aussage selbst als erster Satz
Verstärker wie „wirklich“ oder „tatsächlich“derselbe Satz ohne das Wort
CodeKommentare, die den Code nacherzählenein Kommentar nur für einen Grund, den der Code nicht zeigt
stiller Rückfallwert bei einem Fehlerein sichtbarer Fehler an der Grenze des Systems
OberflächeFarbverläufe, Glaseffekte und Leuchteffektenur, wenn das Design-System sie vorsieht
kleines Label in Großbuchstaben über einer Überschriftdie Überschrift allein

Wie die Regeln in jede Session kommen

Die Regeln liegen an einer Stelle, sodass alle Nutzer im Team mit derselben Fassung arbeiten.

  1. 1

    Der Betreiber pflegt die Datei

    Die Regeln stehen in RULES.md im Repository auf GitHub.

  2. 2

    themis lädt sie beim Start

    Bei jedem Start einer Session holt das Plugin die aktuelle Fassung aus dem Repository.

  3. 3

    Claude arbeitet mit den Regeln

    Claude erhält den Inhalt der Datei als Kontext für die ganze Session.

Eine Änderung an der Datei gilt ab der nächsten Session bei allen Nutzern. Eine laufende Session arbeitet mit der Fassung weiter, die sie beim Start geladen hat.

Wenn der Betreiber die Datei leert, gelten ab der nächsten Session keine Regeln mehr.

Plugin entfernen

Deinstallation im Terminal
$~/themis/uninstall.sh

Danach startet Claude Code ohne die gemeinsamen Regeln.
