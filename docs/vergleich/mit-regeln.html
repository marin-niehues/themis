themis GitHub

Eine Regeldatei für jede Claude-Code-Session im Team

themis ist ein Plugin für Claude Code. Es lädt beim Start jeder Session die gemeinsame Regeldatei aus einem GitHub-Repository und gibt sie Claude als Kontext, damit Claude Texte, Code und Oberflächen ohne die typischen Muster von Sprachmodellen schreibt.

gh repo clone marin-niehues/themis ~/themis
~/themis/install.sh
Repository öffnen

Der Browser hat den Zugriff auf die Zwischenablage verweigert. Markiere die Befehle und kopiere sie von Hand.

Für die Installation brauchst du Claude Code und die GitHub CLI gh mit Zugriff auf das Repository.

Was beim Start einer Session passiert

  1. Du startest Claude Code in einem beliebigen Projekt.
  2. themis holt die aktuelle Regeldatei aus dem Repository auf GitHub.
  3. Claude erhält die Regeln als Kontext und wendet sie auf alles an, was es in dieser Session schreibt.

Eine Änderung gilt für alle

Die Regeln liegen an einer Stelle im Repository. Wenn jemand im Team eine Regel ändert und den Commit pusht, arbeitet ab der nächsten Session jeder mit der neuen Fassung, ohne dass jemand eine Datei in seine Projekte kopieren muss.

CLAUDE.md je Person themis
Ort der Regeln auf jedem Rechner einzeln ein Repository auf GitHub
Änderung verteilen jede Person passt ihre Datei an ein Commit
Stand im Team weicht mit der Zeit ab gleich ab der nächsten Session

Was die Regeln ändern

Jede Regel benennt ein Muster, das in Texten von Sprachmodellen häufiger vorkommt als in Texten von Menschen. Sie gibt an, was Claude stattdessen schreibt.

Bereich Muster Ersatz
Text Gedankenstrich als Satzzeichen Komma, Punkt, Doppelpunkt oder Klammer
Text „nicht X, sondern Y“ als Einstieg in eine Aussage die Aussage über die Sache selbst
Text „Experten sagen“ oder „Studien zeigen“ die konkrete Quelle oder keine Aussage
Code Kommentare, die den Code nacherzählen ein Kommentar nur für einen Grund, den der Code nicht zeigt
Code stiller Rückfallwert nach einem Fehler der Fehler bleibt sichtbar
Oberfläche kleines Label in Großbuchstaben über der Überschrift die Überschrift allein
Oberfläche Formular meldet Erfolg vor der Antwort des Servers Erfolgsmeldung erst nach der Bestätigung

Die vollständige Fassung steht in RULES.md im Repository.
