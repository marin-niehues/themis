# Aufgaben F2

Bearbeite jede Aufgabe. Gib zu jeder Aufgabe nur den verlangten Text oder Code aus, ohne Kommentar dazu.

## F14. Sprechertext für einen Sprachassistenten
Schreib die Antwort eines Sprachassistenten auf die Frage „Gibt es heute neue Ausschreibungen für mich?“ Es gibt 4 neue, davon 1 mit Frist morgen.

## F15. Folientext
Schreib den Text für eine Präsentationsfolie: Ergebnisse der Nutzerumfrage. 61 % wünschen Teams-Benachrichtigungen, 24 % eine App, 15 % nichts davon. 212 Antworten.

## F16. Konferenz-Abstract
Schreib ein Abstract (höchstens 120 Wörter) für einen Vortrag von Mira auf einer Produktkonferenz: Wie das Team von Lotse Nutzerwünsche priorisiert. Methode: monatliche Interviews mit fünf Nutzern, Bewertung nach Häufigkeit und Aufwand.

## F17. Speaker-Bio
Schreib eine Speaker-Bio in der dritten Person (höchstens 60 Wörter). Mira Lange ist Product Owner bei Beispiel Medien und verantwortet das Ausschreibungsradar Lotse. Davor drei Jahre Beratung im öffentlichen Sektor.

## F18. Empfehlung
Schreib zwei Sätze für eine Empfehlung auf LinkedIn für Ben Schulz, Entwickler. Er hat den Import für 16 Vergabeportale gebaut und neue Kollegen eingearbeitet.

## F19. Antwort auf Kritik
Ein Nutzer schreibt öffentlich auf LinkedIn: „Lotse schickt mir ständig irrelevante Ausschreibungen.“ Fakt: Seine Branchenfilter umfassen 14 Branchen. Schreib eine öffentliche Antwort im Namen des Lotse-Teams.

## F20. Hinweis auf eine neue Funktion
Schreib den Text eines kleinen Hinweises in der Anwendung, der einmalig auf den neuen Filter nach Auftragswert aufmerksam macht.

## F21. Bestätigung einer Anmeldung
Schreib die Bestätigungsseite nach der Anmeldung zum Webinar am 14. Januar. Der Link zum Webinar kommt einen Tag vorher per E-Mail.

## F22. Kurzbeschreibung im Repository
Schreib die Kurzbeschreibung (ein Satz) für das GitHub-Repository von csvclean.

## F23. Entschuldigung an eine Kollegin
Schreib eine Slack-Nachricht an Anna. Du hast ihren Branch versehentlich mit force-push überschrieben. Ihr letzter Stand ist im Reflog von gestern 17 Uhr noch vorhanden, du hast ihn wiederhergestellt.

## F24. Rückfrage
Ein Kunde bittet: „Können Sie den Bericht etwas ausführlicher machen?“ Schreib eine Rückfrage, die klärt, was genau er meint.

## F25. Absage eines Termins
Schreib eine Nachricht an einen Kunden, dass das Meeting am Donnerstag ausfallen muss, weil du krank bist. Schlag Dienstag oder Mittwoch nächster Woche vor.
