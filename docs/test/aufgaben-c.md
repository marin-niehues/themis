# Aufgaben C

Bearbeite jede Aufgabe. Gib zu jeder Aufgabe nur den verlangten Text oder Code aus, ohne Kommentar dazu.

## C1. Leerer Zustand
Schreib den Text für den leeren Zustand einer Liste „Gespeicherte Suchen“ in einer Web-Anwendung. Der Nutzer hat noch keine Suche gespeichert. Eine Suche speichert man über die Schaltfläche „Suche speichern“ auf der Ergebnisseite.

## C2. Fehlermeldung
Schreib die Fehlermeldung für ein Formular, wenn die eingegebene E-Mail-Adresse kein @ enthält.

## C3. Bestätigungsdialog
Schreib Titel, Text und Schaltflächen eines Dialogs zum Löschen eines Projekts. Gelöschte Projekte lassen sich 30 Tage lang im Papierkorb wiederherstellen.

## C4. Onboarding
Schreib den Text für Schritt 2 von 3 eines Onboardings. Der Nutzer wählt hier die Branchen aus, für die er Ausschreibungen sehen will. Er kann später in den Einstellungen weitere Branchen hinzufügen.

## C5. Einstellungen
Schreib Bezeichnung und Erklärtext für eine Einstellung: „Tägliche E-Mail“. Wenn sie an ist, bekommt der Nutzer jeden Morgen um 7 Uhr eine E-Mail mit neuen Ausschreibungen.

## C6. 404-Seite
Schreib den Text einer 404-Seite für die Web-Anwendung Lotse.

## C7. Push-Benachrichtigung
Schreib eine Push-Benachrichtigung: Für die gespeicherte Suche „IT-Dienstleistungen NRW“ gibt es 3 neue Ausschreibungen.

## C8. Code
Schreib eine Python-Funktion, die eine JSON-Datei mit Ausschreibungen einliest und nur die Einträge zurückgibt, deren Feld "wert" über einem übergebenen Schwellenwert liegt. Manche Einträge haben kein Feld "wert".

## C9. Code-Review-Kommentar
Schreib einen Kommentar zu einem Pull Request. Problem: In der Funktion load_tenders wird die Datenbankverbindung nie geschlossen. Bei vielen Aufrufen gehen die Verbindungen aus.
