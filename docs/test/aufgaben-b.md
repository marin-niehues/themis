# Aufgaben B

Bearbeite jede Aufgabe. Gib zu jeder Aufgabe nur den verlangten Text oder Code aus, ohne Kommentar dazu.

## B1. Confluence-Seite
Schreib den Einstieg einer Confluence-Seite (höchstens 150 Wörter). Thema: Das Team stellt die Zeiterfassung von Excel auf das Tool Clockify um. Start am 1. Januar. Grund: Monatlich gehen etwa 6 Stunden in das Zusammenführen der Excel-Dateien. Schulung am 15. Dezember.

## B2. Release-Notes
Schreib die Release-Notes für Version 2.4 einer Web-Anwendung. Neu: Filter nach Auftragswert. Behoben: Umlaute im PDF-Export unter Firefox. Geändert: Die Suche ignoriert jetzt Groß- und Kleinschreibung.

## B3. README
Schreib den Einstieg eines README für ein internes Python-Tool namens csvclean. Es entfernt leere Zeilen und doppelte Einträge aus CSV-Dateien. Installation mit pip install csvclean. Aufruf: csvclean eingabe.csv -o ausgabe.csv.

## B4. Produktbeschreibung
Schreib eine Produktbeschreibung für die Website eines Ausschreibungsradars namens Lotse. Fakten: Lotse durchsucht täglich die Vergabeportale von Bund und Ländern. Es filtert nach Branchen und Auftragswert. Nutzer bekommen jeden Morgen eine E-Mail mit neuen Ausschreibungen.

## B5. Hero einer Landingpage
Schreib Überschrift, Unterzeile und Schaltflächentext für den Hero-Bereich der Landingpage von Lotse (Fakten wie in B4).

## B6. LinkedIn-Beitrag
Schreib einen LinkedIn-Beitrag von Mira, Product Owner bei Beispiel Medien. Anlass: Lotse 2.0 ist live. Neu ist der Filter nach Auftragswert. Mira bedankt sich beim Entwicklungsteam.

## B7. Newsletter
Schreib den Einleitungsabsatz eines Kunden-Newsletters im Dezember. Inhalt des Newsletters: neue Funktion Auftragswert-Filter, Betriebsferien vom 23. Dezember bis 2. Januar, Webinar am 14. Januar.

## B8. Stellenanzeige
Schreib den ersten Absatz einer Stellenanzeige für eine Werkstudentin oder einen Werkstudenten im Bereich Datenanalyse, 15 Stunden pro Woche, in Köln, Arbeit mit Python und SQL am Ausschreibungsradar Lotse.
