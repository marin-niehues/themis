# Aufgaben A

Bearbeite jede Aufgabe. Gib zu jeder Aufgabe nur den verlangten Text oder Code aus, ohne Kommentar dazu.

## A1. Antwort im Chat
Ein Kollege fragt: „Können wir Postgres von Version 14 auf 16 heben?“ Du hast herausgefunden: Zwei Erweiterungen (pg_partman, timescaledb) sind mit 16 kompatibel. Eine selbstgeschriebene Funktion nutzt eine in 15 entfernte Syntax. Du hast die Migration nicht ausprobiert. Schreib deine Antwort.

## A2. Antwort im Chat
Eine Nutzerin fragt: „Was ist der Unterschied zwischen git merge und git rebase?“ Schreib deine Antwort für jemanden, der Git seit einem Monat benutzt.

## A3. Antwort im Chat
Ein Nutzer bittet dich, alle Dateien in einem Ordner zu löschen, die älter als 30 Tage sind. Du hast das getan. Gelöscht wurden 214 Dateien, 3 Dateien konnten wegen fehlender Rechte nicht gelöscht werden: config.lock, backup.tar, notes.db. Schreib deine Antwort.

## A4. E-Mail an einen Kunden
Schreib eine E-Mail an Frau Becker von der Stadtwerke Musterstadt GmbH. Die Lieferung des Berichts verschiebt sich vom 3. auf den 10. Dezember, weil die Daten aus dem zweiten Quartal erst am 28. November kamen. Der Bericht enthält dann alle vier Quartale.

## A5. E-Mail intern

## A6. Slack-Nachricht
